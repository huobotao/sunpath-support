隐私政策使用与支持

本政策说明悉尼理想住宅生成器如何处理项目内容，以及地图、文档、分享和支持联系涉及的数据。它适用于本版本的应用功能；你选择使用的 Apple 服务、文件服务、分享目标和邮件服务，也可能按照各自的规则处理数据。

项目与本地计算

偏好权重、候选排名和参数化住宅概念模型在设备上处理。本版本没有开发者账户注册或登录、广告、行为分析，也没有向开发者服务器上传项目的功能。

应用内置 16 个悉尼概念候选点。候选指标、评分和三种场景用于比较偏好与预设假设，并非对真实房产、建筑遮挡、规划项目或安全条件的评估。三维住宅展示设计意图，不代表经过实测或模拟验证的日照、通风、避风或眩光效果。

Apple 地图与网络

地图由 Apple MapKit 提供。进入和浏览地图时，可能通过网络向 Apple 请求地图内容，相关服务及其数据处理由 Apple 提供。应用并非所有功能都完全离线，本政策也不代表 Apple 不处理服务请求或相关数据。

地图只负责显示，不参与概念评分。应用不请求设备实时定位；地图上的候选点坐标来自内置概念数据，并非你的当前位置。

项目文档、保存位置与删除

项目以 .sihome 文档保存，内容包括项目名称、创建及更新时间、偏好权重、场景、住宅原型、选中候选点，以及数据包身份、版本校验和绑定历史。

文档由系统文档界面管理，保存在你选择的位置。若选择 iCloud Drive 或其他文件服务，服务提供方可能根据你的设置同步文件。应用没有自建的项目云端账户或项目上传服务器；这不排除系统文件服务进行同步。

请在原保存位置管理或删除文档，并按所用文件服务的方式检查“最近删除”、备份及其他副本。卸载应用不保证删除保存在云端、其他位置或分享接收方处的文档。开发者不能通过应用远程删除你在这些位置保存的项目。

你主动选择的分享与外链

在提供“分享摘要”入口的布局中，只有你主动使用系统分享界面并选择目标后，摘要才会交给相应应用或服务。摘要可包含项目名称、候选点、场景、住宅原型、概念评分及数据包说明；请在发送前确认是否适合向接收方披露。摘要不会自动发送给开发者。

数据来源链接如有提供，仅在你点击后打开对应网站。本版本内置概念数据未提供来源网站链接。外部网站或分享服务的数据处理适用其各自规则。

设备访问权限

本版本未实现摄像头、麦克风、照片或设备实时定位采集。三维住宅使用虚拟相机展示概念模型，并非摄像头 AR 测量。

支持邮件与隐私问题

支持邮箱：huobotao@hotmail.com。点击邮箱链接只会请求打开邮件应用，不会自动发送邮件。

如果你主动发送邮件，你的发件地址、正文和自行添加的附件会交给邮件服务和支持收件方，用于处理你提出的问题。请勿发送密码、验证码，或与问题无关的私人文档；截图也请先遮盖私人信息。

需要查询或请求删除你曾主动发送的支持邮件时，可通过同一邮箱说明请求。邮件及其备份的处理受相应邮件服务机制影响；这与删除你自行保存的项目文档是不同的操作。

本网站的托管

本隐私与支持网站由 GitHub Pages 托管。GitHub 说明，访问 GitHub Pages 网站时会记录并保存访问者的 IP 地址，用于安全目的，无论访问者是否登录 GitHub。本页不添加广告、分析脚本、表单或外部嵌入资源。

有关托管服务的数据处理，请参阅 GitHub Pages 数据收集说明和 GitHub 隐私声明。应用内的项目计算与访问本网站是不同的数据处理场景。

说明更新

应用的数据处理方式变化时，会相应更新说明。阅读本页时，可通过上方日期识别文本版本。如有疑问，请联系支持邮箱。

概念结果不构成房产、规划、工程或安全建议。实际决策需要使用正式资料并另行核验。
